# Valheim Cheat Menu — BepInEx-плагин — by rskx

Чит меню для *одиночной игры / своего сервера*.

## Установить BepInEx

1. Скачайте *BepInEx 5.4.23.2 x64* — с github сайта: https://github.com/BepInEx/BepInEx/releases?after=v5.4.4
2. Распакуйте архив в корень игры.
3. Запустите игру один раз, чтобы BepInEx создал папку `plugins` и `LogOutput.log`.
4. Сам чит ValheimObsidian.dll поместите в папку `plugins`.

## Запуск

1. Запусти *Valheim*.
2. Чтобы открыть чит меню нажми F1 (Так же чит открывается и в лобби игры).
